# Repository Instructions for AI Agents

The authoritative coding standards for this repository live in [`CLAUDE.md`](./CLAUDE.md).

All agents working on this Unity project must read and follow `CLAUDE.md` before analyzing code, implementing features, fixing defects, refactoring, or reviewing changes. That file defines the shared conventions for naming, formatting, class structure, method design, serialization, events, documentation, testing, and completion reporting.

Project-specific context (Unity version, packages, architecture, and conventions) is documented in [`Docs/AI/UnityProjectContext.md`](./Docs/AI/UnityProjectContext.md).
